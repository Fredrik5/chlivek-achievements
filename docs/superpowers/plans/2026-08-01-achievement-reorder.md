# Admin Achievement Reordering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an admin reorder normal (non-secret) achievements within their category, and have that order reflected both in the admin Achievements tab and on the player dashboard.

**Architecture:** Add an `order` integer column to `Achievement`, backfilled to match today's implicit `createdAt` order. Achievement listing endpoints sort by `[categoryId, order]` instead of `createdAt`. A new admin-only endpoint swaps the `order` of two adjacent same-category achievements. The admin UI gets up/down buttons per row that call this endpoint.

**Tech Stack:** Next.js 16 (App Router, route handlers), Prisma 7 (`prisma-client` generator) against SQLite, React 19 client components, no test framework in this repo (verification is manual/DB-script based).

## Global Constraints

- Reordering is scoped **per category** — achievements only move within their own category's list (spec: "Scope").
- Secret achievements are unaffected: their admin list keeps sorting by `createdAt`, no reorder UI for them (spec: "Scope").
- Migration must be a visual no-op: today's implicit `createdAt` order becomes tomorrow's explicit `order` value (spec: "Data model").
- New achievements append to the end of their category (`max order + 1`); moving an achievement to a different category also appends it to the end of the new category (spec: "Order assignment rules").

- [ ] **Step 3: Hand-edit the migration to add the backfill**

Open the generated `migration.sql` and append this backfill statement after the `ALTER TABLE`:

```sql
-- AlterTable
ALTER TABLE "Achievement" ADD COLUMN "order" INTEGER NOT NULL DEFAULT 0;

-- Backfill: number achievements 0, 1, 2, ... within each category (NULL
-- categoryId group = all secret achievements together), ordered by their
-- existing createdAt so this is a no-op for today's visible order.
UPDATE "Achievement"
SET "order" = (
  SELECT COUNT(*)
  FROM "Achievement" AS a2
  WHERE a2."categoryId" IS "Achievement"."categoryId"
    AND (
      a2."createdAt" < "Achievement"."createdAt"
      OR (a2."createdAt" = "Achievement"."createdAt" AND a2."id" < "Achievement"."id")
    )
);
```

### Task 4: Reorder endpoint

**Files:**
- Create: `src/app/api/admin/achievements/[id]/reorder/route.ts`

**Interfaces:**
- Consumes: `requireAdmin()` from `@/lib/auth`, `handleApiError` from `@/lib/api`, `prisma` from `@/lib/db`.
- Produces: `POST /api/admin/achievements/:id/reorder` with body `{ direction: "up" | "down" }` → `{ ok: true }` on success (200) or `{ error: string }` (400/404), consumed by Task 5's UI.

- [ ] **Step 1: Implement the endpoint**

Create `src/app/api/admin/achievements/[id]/reorder/route.ts`:

```ts
import { NextRequest, NextResponse } from "next/server";
import { prisma } from "@/lib/db";
import { requireAdmin } from "@/lib/auth";
import { handleApiError } from "@/lib/api";

export async function POST(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> },
) {
  try {
    await requireAdmin();
    const { id } = await params;
    const body = await request.json();
    const direction = body.direction;

    if (direction !== "up" && direction !== "down") {
      return NextResponse.json({ error: "Neplatný směr." }, { status: 400 });
    }

    const achievement = await prisma.achievement.findUnique({ where: { id } });
    if (!achievement) {
      return NextResponse.json({ error: "Achievement nenalezen." }, { status: 404 });
    }

    const siblings = await prisma.achievement.findMany({
      where: { categoryId: achievement.categoryId },
      orderBy: [{ order: "asc" }, { createdAt: "asc" }],
    });

    const index = siblings.findIndex((s) => s.id === id);
    const neighborIndex = direction === "up" ? index - 1 : index + 1;
    const neighbor = siblings[neighborIndex];

    if (!neighbor) {
      return NextResponse.json({ ok: true });
    }

    await prisma.$transaction([
      prisma.achievement.update({ where: { id: achievement.id }, data: { order: neighbor.order } }),
      prisma.achievement.update({ where: { id: neighbor.id }, data: { order: achievement.order } }),
    ]);

    return NextResponse.json({ ok: true });
  } catch (err) {
    return handleApiError(err);
  }
}
```
